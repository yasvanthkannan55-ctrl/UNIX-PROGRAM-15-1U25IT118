# UNIX PROGRAM – Add Group and Delete Group

## Aim

To create a group and delete the group using Linux commands.

## Algorithm

1. Open Terminal on a Linux machine.
2. Create a group using the `groupadd` command.
3. Delete the group using the `groupdel` command.
4. Close the Terminal.

## Student Task

Complete the `starter.sh` file.

Your program must:

- Create the required Linux group.
- Delete the required Linux group.
- Use the appropriate Linux commands.
- Execute successfully on Ubuntu/Linux.
